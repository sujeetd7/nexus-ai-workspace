Coding Standards

Use TypeScript strict mode.

Prefer interfaces over types where appropriate.

Avoid any.

No duplicated logic.

No hardcoded URLs.

Use environment variables.

Prefer async/await.

Use builder pattern where already adopted.

Use existing logger.

Never console.log except temporary debugging.

All services should expose DTOs.

Always use dependency injection.

Every executor returns ExecutionResult.

Every integration module must expose getClient().

Use existing architecture.
